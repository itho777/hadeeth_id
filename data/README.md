This directory will hold pre-indexed CDN JSON data files for the Hadith collections.

Structure (to be generated by scripts/fetch_and_process.py):
  data/
  ├── index.json             ← Master index of all books/chapters
  ├── bukhari/
  │   ├── index.json         ← Bukhari chapter index
  │   ├── 1.json             ← Hadith 1 full payload (all languages)
  │   └── ...
  ├── muslim/
  │   └── ...
  └── ...

These files are served directly by Cloudflare Pages CDN with unlimited bandwidth.
