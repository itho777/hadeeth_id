Data Sources

HADEETH.ID aggregates hadith text from multiple authoritative open-source databases. This page documents every collection available on the platform, its origin, and our validation approach.

verified_user

Core principle: Hadith text is never overwritten, never deleted, never altered. All source data is stored verbatim. Any editorial notes are clearly labelled and separated from the original text.

source Primary Databases & Dynamic Anchoring

Primary Anchor

Fawazahmed0 DB

Used as the universal anchor across almost all collections due to its comprehensive, gap-free numbering (e.g., 7,500+ hadiths for Bukhari). Our text-matching engine dynamically maps all other datasets to its Arabic text.

Source: github.com/fawazahmed0

Linked Source

Lidwa Hadith DB

Dynamically mapped to the anchor to supply Indonesian translations and isnad chains for the Kutubut Tis'ah (9 core books).

Source: Lidwa Pusaka

Linked Source

AhmedBaset DB

Dynamically mapped to the anchor to supply English translations for the secondary collections. Acts as the fallback anchor if Fawazahmed0 is unavailable.

Source: hadithapi.com

architecture Technical Architecture

Static JSON CDN

All hadith data is served as pre-built JSON files via Cloudflare Pages CDN. No database queries on the client — data is fetched once per session.

Edition System

Each kitab has multiple editions identified by prefix: ara-bukhari, eng-bukhari, ind-bukhari. Each edition is a separate JSON file.

Narrator Data

Narrator (rawi) profiles and isnad chains sourced from the Lidwa narrator database, supplemented by scholarly commentary (syarah) from linked data pipelines.

fact_check Data Integrity Policy

✅ Verbatim preservation — Hadith text is stored exactly as received from the source database. No paraphrasing, summarising, or reformatting of the original Arabic or translation.

✅ Non-destructive versioning — Original source files are archived in data/raw_baseline/. Any processing scripts produce new files, never mutating the originals.

✅ Open-source pipeline — All import and processing scripts are available in the project repository for independent audit.

✅ Grade transparency — Hadith grading (Sahih, Hasan, Da'if) is displayed exactly as provided by the source database. No editorial grading is applied.

⚠️ Translation disclaimer — English and Indonesian translations are those provided by the source databases. For scholarly use, always verify against authoritative printed editions.
