Data Sources & Credits

HADEETH.ID aggregates hadith text from multiple authoritative open-source databases and contributors. This page documents every collection available on the platform, its origin, and our validation approach.

verified_user

Core principle: Hadith text is never overwritten, never deleted, never altered. All source data is stored verbatim. Any editorial notes are clearly labelled and separated from the original text.

source Data Sources, Credits & Anchoring

Primary Anchor

Fawazahmed0 DB

Used as the universal text anchor. Supplies multilingual support for 11+ languages (Arabic, English, Indonesian, Bengali, French, Russian, Tamil, Turkish, Urdu, etc) across Kutubus Sittah, Malik, Tabarani, and 40-Hadith collections.

Source: fawazahmed0.github.io

Linked Source

Lidwa Hadith DB

Dynamically mapped to supply Indonesian translations, isnad chains (Sanad), and Kedudukan (Status) / Grading specifically for the core 9 books (Kutubut Tis'ah).

Source: Lidwa Pusaka

Linked Source

AhmedBaset DB

Provides comprehensive mapping for secondary collections (Adab, Bulugh, Mishkat, Riyad, Shamail, Nawawi, Qudsi, Shah) and base anchors for English/Arabic alignments.

Source: hadithapi.com

Grading Source

Usm12345

Explicit crediting for rigorous hadith grading.

  • Tirmidhi: 847 Da'if, 1 Mawdu'
  • Abu Dawood: 847 Da'if, 18 Shadh, 26 Munkar, 2 Mawdu'
  • Ibn Majah: 1,074+ Da'if
  • Nasa'i: 235 Da'if, 6 Munkar
  • Ahmad: 300+ Da'if (In progress)

Source: github.com/Usm12345

ID Collections

Irsyadulibad & MJNA

Crucial sources for Musnad Syafi'i, Mustadrak Imam Al Hakim, Shahih Ibnu Khuzaimah, Sunan Ad-Daruquthni, and Shahih Ibnu Hibban (providing Arabic + Indonesian translations).

Sources: irsyadulibad, mjna.or.id

Syarah & Ref

meeAtif & Dorar

meeAtif provides JSON alignments for Kutub al-Sittah (AR, EN, Grading EN, and sunnah.com references). Dorar provides detailed Arabic Syarah (commentaries).

Sources: meeAtif, Dorar

Rijal Index

Narrators & Biographies (Kaggle + Lidwa)

The Hadeeth.id narrator engine combines data from Lidwa's internal database (providing exact collection counts and basic bios for 8,600+ narrators) with Kaggle scholarly remarks and Jarh wa Ta'dil assessments for primary transmitters.

Sources: Lidwa DB + Kaggle

architecture Technical Architecture

Static JSON CDN

All hadith data is served as pre-built JSON files via Cloudflare Pages CDN. No database queries on the client â€” data is fetched once per session.

Edition System

Each kitab has multiple editions identified by prefix: ara-bukhari, eng-bukhari, ind-bukhari. Each edition is a separate JSON file.

Narrator Data

Narrator (rawi) profiles and isnad chains sourced from the Lidwa narrator database, supplemented by scholarly commentary (syarah) from linked data pipelines.
